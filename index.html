Backend API Endpoints
Method Endpoint Description & Parameters
GET /api/health System status: backend, Elasticsearch, Ollama. Returns JSON with service states and available models.
GET /api/search q query · mode bm25|semantic|hybrid|filename · lang en|de|es|auto · size results · ext file filter
GET /api/es-search Elasticsearch-native search with BM25, kNN, hybrid modes, fuzzy matching, and SRT timestamp support.
POST /api/ask RAG pipeline — streams answer via SSE. Body: {"q":"…","model":"llama3","lang":"auto","history":[…]}
GET /api/ollama-models List all locally available Ollama models with sizes and parameter counts.
GET /api/file-text path — extract and return plain text from any indexed file (PDF, DOCX, MP4 subtitle, etc.).
GET /api/analytics Corpus-wide aggregations: file type distribution, language breakdown, top terms, indexing timeline.
GET /api/translate-status Translation worker progress: queued / in-progress / completed documents per language pair.
POST /api/ocr Soon Upload PDF or image → extract text via selected OCR engine. Returns structured JSON with pages, confidence, and detected tables.

Launchers
🚀
Startup Launcher
launcher.py  ·  start.sh  ·  start.bat
Opens browser startup screen, checks services, starts backend automatically.
›

Opens a visual startup progress screen in the browser, installs Python dependencies if missing, checks Elasticsearch and Ollama availability, then starts the Flask backend. All platforms — no terminal knowledge required.

# Double-click or run from terminal:

# Windows
start.bat

# Linux / macOS
./start.sh

# Direct Python (any platform)
python3 launcher.py

# Options
python3 launcher.py --backend-port 8080
python3 launcher.py --no-browser
python3 launcher.py --no-install
⚡
Dev Environment Setup
setup-dev.py  ·  setup-dev.sh  ·  setup-dev.bat
Full stack: Docker + Elasticsearch + indexing + Flask.
›

Starts Docker, launches an Elasticsearch container, indexes a directory (interactive or from CLI), starts the Flask backend, optionally sets up Ollama, and opens the Search Console in the browser.

# Interactive
python3 setup-dev.py

# Index directory (incremental)
python3 setup-dev.py /path/to/courses

# Wipe index + full reindex
python3 setup-dev.py --reset /path/to/courses

# Filter by file type
python3 setup-dev.py --ext pdf,srt /path/to/courses

# Windows / Linux wrappers accept the same arguments
setup-dev.bat --reset "C:\Courses"
./setup-dev.sh --reset /path/to/courses
Core Components
🗂️
Catalog Generator
catalog_generator.py
Scans a directory and produces course_catalog.md + .html
›

Recursively scans a documents directory and generates a structured Markdown and HTML catalog listing all videos, PDFs, documents, subtitles, and media files organized by folder.

python3 catalog_generator.py /path/to/courses
python3 catalog_generator.py /path/to/courses --output ./output
🌐
Backend Server
catalog_server.py
Flask REST API — search, RAG, file viewer, analytics
›

Lightweight Flask server that powers search, RAG answer streaming, Elasticsearch integration, file text extraction, analytics aggregations, and translation status. Runs on port 5000.

python3 catalog_server.py --path /path/to/courses
python3 catalog_server.py --path /path1;/path2   # multiple roots
python3 catalog_server.py --port 8080            # custom port
📥
Document Indexer
es_indexer.py
Index documents into Elasticsearch with BM25 + kNN vectors
›

Extracts text from PDF, DOCX, XLSX, PPTX, SRT/VTT, MP4 (via subtitles), JSON, CSV, and plain text files. Generates kNN embeddings via a local sentence-transformer model. Supports incremental indexing using SHA-256 hashes to skip unchanged files.

# Incremental (add new / changed files only)
python3 es_indexer.py --path /path/to/courses

# Full reindex
python3 es_indexer.py --path /path --reset

# Without semantic vectors (faster, smaller index)
python3 es_indexer.py --path /path --reset --no-vectors

# Filter by file type
python3 es_indexer.py --path /path --ext pdf,srt,md
📊
Index Status
es_status.py
Print a summary of what is indexed in Elasticsearch
›

Connects to Elasticsearch and displays a breakdown of indexed documents by file type, language, index size, last-modified timestamps, and vector coverage.

python3 es_status.py
python3 es_status.py --es-url http://127.0.0.1:9200 --index course_catalog
Background Workers
🌍
Translation Worker
translation_worker.py
Daemon: translate documents to a canonical language via Ollama
›

Background daemon that detects the language of each indexed document and translates it to the configured CANONICAL_LANGUAGE (env.py). Uses Ollama with exponential backoff, writes canonical_content field into Elasticsearch for cross-lingual search.

python3 translation_worker.py
# Progress is written to translation_status.json
# Configure in env.py: CANONICAL_LANGUAGE, TRANSLATION_MODEL
🧠
Analytics Worker
analytics_worker.py
LLM auto-summarization, discourse metrics, NER tagging
›

Reads indexed documents, generates a one-paragraph AI summary (doc_summary field) using Ollama, computes discourse metrics (lexical richness, personal pronoun distribution), and optionally runs spaCy NER to extract named entities.

python3 analytics_worker.py
# Progress written to analytics_status.json
Utilities
🤖
Ollama Setup
ollama_setup.py
Detect hardware, recommend and pull Ollama models
›

Detects CPU, RAM, GPU (NVIDIA CUDA / AMD ROCm / Apple Silicon) and recommends the best Ollama model for your hardware. Provides an interactive wizard to install Ollama and pull the recommended LLM and embedding models.

python3 ollama_setup.py            # interactive wizard
python3 ollama_setup.py --json     # machine-readable hardware profile
🧪
Test Runner
run_tests.py
End-to-end validation: search quality, RAG accuracy, edge cases
›

Runs four test suites against a live backend: 9a cross-lingual language agnosticism, 9b RAG answer quality, 9c search mode comparison (BM25 vs semantic vs hybrid), 9d edge cases (empty query, special chars, very long query). Results saved to docs/test_results.md.

# Requires catalog_server.py running first
python3 run_tests.py               # all tests
python3 run_tests.py --no-rag      # skip RAG (faster)
python3 run_tests.py --test 9a     # single suite
Option A — Native (No Docker)
1

Run the native launcher

Creates a virtual environment, installs dependencies, generates the catalog, and starts the Flask server. All in one command.

python3 start.py "/path/to/your/courses"
2

Open the application

The backend runs at http://localhost:5000. The hub page opens automatically, or navigate to http://localhost:5000/ in your browser.

Option B — Full Stack (Elasticsearch + AI)
1

Install Docker Desktop

Required for the Elasticsearch container. docker.com/products/docker-desktop

2

Run the dev setup script

Starts Docker, Elasticsearch, indexes your courses, sets up Ollama, and opens the Search Console.

python3 setup-dev.py "/path/to/your/courses"
3

Install Ollama (optional, for AI Chat)

The setup script will offer to run the Ollama wizard automatically, or run it manually:

python3 ollama_setup.py
4

Open the Search Console or AI Chat

Both are now accessible above. The Search Console also has an inline "Ask" panel for quick RAG queries.

Configuration — env.py
# env.py — edit before running the backend
SEARCH_BASE_PATH  = "/path/to/courses"    # one or more paths separated by ;
ES_URL            = "http://127.0.0.1:9200"
CANONICAL_LANGUAGE = "en"                 # translate everything to English
TRANSLATION_MODEL  = "llama3"             # Ollama model for translation
OLLAMA_URL         = "http://localhost:11434"
