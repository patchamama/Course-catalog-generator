        🧠
        Embedding Model Configuration
        ▸
      

      

        

          Choose the embedding model for semantic (kNN) search. MiniLM and mpnet are
          English-biased — use canonical language to translate queries at search time.
          mE5-small and LaBSE are natively multilingual — no translation needed,
          smaller index, faster queries. Changing the model requires a full reindex.
        

        

          

            
            
          

        


        
        

          

            
          

          

            

              

                
                
              

              

                
                
              

            

            

              Queries will be translated to the canonical language before embedding (background mode via Ollama).
              Reduces index size vs storing multi-language vectors. Not needed with mE5-small or LaBSE.
            

          

          

            ★ The selected model is natively multilingual — canonical language translation is not needed.

        📦
        Export / Import index (move to another machine)
        ▸
      

      

        

          Index on a fast machine (e.g. a Mac with the big embedding model), export everything as one
          archive, copy it to this machine and import it — no re-indexing. The backend packs / unpacks the
          Elasticsearch Docker volume and restarts Elasticsearch for you. Works from localhost only.
        

        
Open this card to check Docker…


        
📤 Export (this machine → file)

        

          

            
            

              
              
            

            Elasticsearch is stopped for the duration of the copy (a consistent snapshot) and restarted afterwards.
          

        

        


        
📥 Import (file → this machine) — replaces ALL current Elasticsearch data

        mdtranslator — Markdown Translator
        ▸
      

      

        

          Prepare a Markdown document for translation. Splits content into translatable segments
          and generates translation-ready output (_mdtranslator/translate-prepare.mjs).

        mdsplit — Markdown Splitter
        ▸
      

      

        

          Split a Markdown file into multiple files by heading level.
          Optionally generates a table of contents (_mdsplit/mdsplit.py).
        

        

          

            
            
          

        

        

          

            
            
          

          

            
            
          

        

        

        

        
        

      

    


    
    

      

        🖼️
        mdImageDownloader — Download Images from Markdown
        ▸
      

      

        

          Download all remote images referenced in a Markdown file and update paths to local copies.
          Optionally keeps original HTML img tags (_mdImageDownloader/download-images.mjs).
        

        

          

            
            
          

        

        

          

            
            
          

        

        

        

        
        

      

    


    
    

      

        ✨
        mdformater — Markdown Formatter
        ▸
      

      

        

          Format and normalize a Markdown document: fix headings, lists, spacing, and optionally
          process images (_mdformater/format-docs.mjs).
        

        

          

            
            
          

        

        

        

        
        

      

    


    
    

      

        🔄
        mdfromhtml — HTML to Markdown Converter
        ▸
      

      

        

          Convert HTML files to Markdown. Three modes available: single file conversion,
          collection (batch convert a directory), and merge (combine converted files into one book).
